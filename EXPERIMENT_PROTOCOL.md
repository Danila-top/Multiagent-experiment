# Multi-agent experiment protocol

## 1. Hypothesis
State the claim being tested.

## 2. Roles
Define each participating agent and its permitted tools.

## 3. Context
Record which shared context each agent receives.

## 4. Interaction
Record the message flow and artifacts exchanged.

## 5. Verification
Use an independent check where practical.

## 6. Result
Separate observed behavior from interpretation.

## 7. Replication
Describe the minimum information required to repeat the experiment.
